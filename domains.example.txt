# Domains to watch for SSL certificate expiry.
#
#   - One domain per line.
#   - Blank lines and lines starting with # are ignored.
#   - Add ":port" to check something other than https, e.g. mail.example.com:993
#
#   - A line in [Brackets] starts a category. Every domain below it belongs to
#     that category until the next [Header]. Categories are optional - a plain
#     list with no headers works fine.
#
#       [Example Product]
#       example.com
#       www.example.com
#       test.example.com
#       qa.example.com
#
# Renewal groups these by DNS zone, not by category: every name under a zone
# your DNS provider manages ends up on one certificate together. You do not
# have to configure that - add the domain here and it follows.
#
#   - Listing "example.com" and "*.example.com" together is fine and expected.
#     The zone then produces two certificates, and the apex goes on the
#     WILDCARD one - it has to, because *.example.com does not match a bare
#     example.com. The other certificate leaves the apex out on purpose: two
#     certificates cannot both serve one name, the exact match would win, and
#     the loser would silently never appear.
#     Both names stay watched either way. This only decides which certificate
#     carries which name, and nothing here needs changing for it.
#
# This file is the shipped example. "First Time Setup.bat" copies it to
# domains.txt, which is yours and is never committed or overwritten.

[Example]
example.com
www.example.com
