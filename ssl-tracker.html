Renewal settings

    
Credentials are encrypted with Windows DPAPI and stored in
    secrets.xml beside this page. They never leave this PC, and they do not
    travel if you copy this folder to another machine.


    

      
      
      
The certificate authority sends expiry warnings here. Required.

    


    
Certificate authorities

    
Each certificate picks an issuer on its own row in the Certificates table.
    Anything not pinned uses the default below. Staging is per authority — staging
    certificates are not trusted by browsers, but they do not count against rate limits,
    so leave it on until a renewal completes cleanly.

    

    
    

      
      
    


    
DNS providers

    
Renewal proves you control a domain by writing a DNS record. Each profile
    below is one DNS account; every zone it manages becomes renewable automatically.
